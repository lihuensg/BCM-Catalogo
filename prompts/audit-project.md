# Prompt — Auditoría integral

Auditá el proyecto completo sin asumir que compilar significa estar correcto.

Leé primero `AGENTS.md` y todos los docs.

Revisá:
- arquitectura;
- duplicación;
- frontend;
- backend;
- contratos;
- DB;
- seguridad;
- rendimiento;
- cache/revalidación;
- UX pública;
- UX admin;
- responsive;
- accesibilidad;
- loading/error/empty;
- tests;
- inconsistencias con documentación.

Clasificá hallazgos:
- crítico;
- alto;
- medio;
- bajo.

Para cada hallazgo:
- evidencia concreta;
- impacto;
- ubicación;
- corrección recomendada.

No modificar código durante la auditoría salvo pedido explícito.
