# Prompt — Build Feature

Implementá la funcionalidad solicitada respetando estrictamente el repositorio existente.

## Procedimiento
1. Leer `AGENTS.md`.
2. Leer docs relevantes.
3. Inspeccionar código relacionado.
4. Identificar contratos y reglas existentes.
5. Proponer internamente el cambio mínimo coherente.
6. Implementar verticalmente.
7. Agregar/actualizar tests.
8. Validar UI si corresponde.
9. Ejecutar gates.

## Reglas
- no duplicar;
- no reescribir módulos sanos;
- no introducir breaking changes silenciosos;
- no cambiar schema sin migration;
- no cambiar reglas de negocio sin actualizar docs;
- no “arreglar” diseño con CSS global de alto impacto sin revisar consecuencias;
- no considerar completo solo por compilar.

## Entrega
Informar:
- causa/objetivo;
- archivos;
- comportamiento;
- tests;
- riesgos;
- deuda pendiente.

No hacer deploy salvo pedido explícito.
